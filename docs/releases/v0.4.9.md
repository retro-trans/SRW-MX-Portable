English story translation of **Super Robot Taisen MX Portable** for PSP,
original Japanese edition **ULJS-00041**. Includes all stages and route branches,
the ending and **all 67 chapter titles**. This remains an experimental build.

### Apply

**The easiest way:** [Retro Trans Tools](https://github.com/retro-trans/retro-trans-tools)
provides a desktop interface for applying translation patches. Download the app
from its Releases page, refresh the catalog, choose **Automatic**, select your
source ISO, wait for analysis and click **Patch**. v0.4.9 is registered in the
verified catalog. **Apply xdelta** also works with the downloaded patch.

**Other ways:** [DeltaPatcher](https://github.com/marco-calautti/DeltaPatcher)
accepts the same `.xdelta` files. Select the matching source ISO and patch.

**Command line:** Get [xdelta3](https://github.com/jmacd/xdelta). You need your own
matching Japanese ISO or the exact published English v0.4.1 image:

| Your source image | Patch |
|---|---|
| Original Japanese PSP release, ULJS-00041 | [SRWMX-English-v0.4.9.xdelta](https://github.com/retro-trans/SRW-MX-Portable/releases/download/v0.4.9/SRWMX-English-v0.4.9.xdelta) |
| Published English v0.4.1, ULJS-00041 | [SRWMX-English-v0.4.1-to-v0.4.9.xdelta](https://github.com/retro-trans/SRW-MX-Portable/releases/download/v0.4.9/SRWMX-English-v0.4.1-to-v0.4.9.xdelta) |

**Original Japanese edition:**

```sh
xdelta3 -d -s "Super Robot Taisen MX Portable (Japan).iso" SRWMX-English-v0.4.9.xdelta "SRWMX English v0.4.9.iso"
```

**Already on the published v0.4.1?** Use the upgrade patch:

```sh
xdelta3 -d -s "SRWMX English v0.4.1.iso" SRWMX-English-v0.4.1-to-v0.4.9.xdelta "SRWMX English v0.4.9.iso"
```

The upgrade requires the exact published v0.4.1 output; local test builds with
the same version label may differ. Full and upgrade patches produce identical
v0.4.9 output. If you get a checksum mismatch, compare your source with
`README-v0.4.9.txt` or `BUILD-MANIFEST.json` in the downloads. Keep source
verification enabled. Other English versions are not supported upgrade sources.

### What changed since v0.4.1

- **Story dialogue completed through the ending.** Adds the remaining campaign
  stages, all mapped route branches, final and hidden stages, unused scenes and
  closing/save messages. The prologue and earlier stages are retained.
- **All chapter titles translated.** Expands the single Stage 1 Super card to all
  67 chapter titles across 205 native copies: 160 translated copies and 45
  existing English copies preserved.
- **Interface text and layout fixes.** Adds terrain labels, shorter weapon names
  where needed, aligned menus and search grids, adjusted option labels and more
  space between active-spirit codes.
- **Narration and dialogue corrections.** Repairs narration timing and incorporates
  the reviewed Aqua, Koji, Blacky and Elvy dialogue fixes.
- **English INTERMISSION header.** Replaces the native bitmap lettering while
  preserving its palette and background. The native 4× Genei LateGo font,
  battle captions and earlier interface work are retained.

Both full and upgrade patches were applied to their specified source images
and matched the complete v0.4.9 output SHA-256. Final readback verifies **51,366 original readable script
uses**, **98,686 unchanged commands**, **205 chapter-card atlases**, the native
font, terrain labels and intermission header. Battle caption readback checked
**51,892 entries with no mismatches**. All release assets were downloaded
and verified before publication.

`BUILD-MANIFEST.json`, `VALIDATION.json` and `SHA256SUMS.txt` follow the Retro Trans
release format. `SHA256SUMS-v0.4.9.txt` also covers the documentation and
font-license downloads. The verified catalog contains this release.

### Playtesting status

**A complete campaign playthrough and physical PSP testing remain pending.**
Targeted PPSSPP checks cover boot, copied-save loading, selected dialogue,
chapter-card rendering and the English intermission header, with texture
replacement disabled. All five enlarged map scripts pass native allocation and
ISO-read probes from the complete-campaign baseline. Ending and closing blocks
pass loading checks; exact ending text passes a renderer probe, which does not
constitute playing the ending scene.

Some bitmap interface labels, including the sortie-preparation header, still
remain Japanese. Report crashes, clipped text and translation issues with the
build version, route, stage and an in-game screenshot.

Use an **in-game save** and restart when changing builds. Emulator save states
retain old code and resources.

### What's included

The prologue, all **54 numbered stages**, **final and hidden stages**, every mapped
route branch, ending, unused scenes and closing/save messages. Also included:
battle captions, pilot/unit/weapon text, library and other database entries,
chapter title cards, narration, terrain labels and menu/status text.
The release provides a full patch from Japanese and an upgrade from published v0.4.1.

The proportional Genei LateGo font uses a native **4× Latin atlas**, with intact
descenders. Font and artwork changes are included inside the patch; no emulator
texture replacement is needed.

### How it was translated

This is **machine translation produced with language models and then edited**.
The complete campaign pass used Sol 6.1 Medium, with six translators sharing
each stage/group, followed by context, terminology and actual-font fit review.
Complete human proofreading has not been performed. Terminology follows
[Akurasu's MX reference](https://akurasu.net/wiki/Super_Robot_Wars/MX).
