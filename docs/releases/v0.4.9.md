# v0.4.9 — all story dialogue and chapter titles

English patch for the Japanese PSP edition **ULJS-00041**. This release expands
v0.4.1's partial campaign translation to **all story dialogue through the ending**
and **all 67 chapter titles**, with the cumulative UI fixes through local 0.4.9.

## Apply

Download `SRWMX-English-v0.4.9.xdelta` and apply it to your own matching **original
Japanese ISO** with [Retro Trans Tools](https://github.com/retro-trans/retro-trans-tools).
Use **Automatic** after refreshing the catalog, or **Apply xdelta** with the
downloaded patch. [DeltaPatcher](https://github.com/marco-calautti/DeltaPatcher)
also accepts the same file.

```sh
xdelta3 -d -s "Super Robot Taisen MX Portable (Japan).iso" SRWMX-English-v0.4.9.xdelta "SRWMX English v0.4.9.iso"
```

This is a full patch from the original ISO. Earlier English builds are not
supported patch sources. Keep checksum verification enabled. Use an **in-game
save** and restart the game when changing versions; emulator save states retain
old code and resources.

## Included

- Prologue, all 54 numbered stages, final and hidden stages, and every mapped
  route branch. Ending, unused scenes and closing/save messages are translated.
- All 67 chapter titles across 205 native title-card copies: 160 translated
  copies and 45 existing English copies preserved.
- English battle captions, menus, pilot/unit/weapon names, library entries,
  terrain names and other database/interface text.
- Proportional Genei LateGo font with a native 4× Latin atlas and intact descenders.
- UI fixes from 0.4.4–0.4.9: shorter weapon names where needed, menu alignment,
  search-grid centering, narration timing, option labels, active-spirit spacing,
  dialogue corrections and the **INTERMISSION** bitmap header.

Font and artwork are patched inside the game. No emulator texture replacement
is needed. `FONT-LICENSE.txt` contains the font acknowledgements and SIL OFL terms.

## Validation and remaining checks

The Retro Trans standard builder applies the patch to the original ISO and
checks the entire reconstructed output. `BUILD-MANIFEST.json`, `VALIDATION.json`
and `SHA256SUMS.txt` record exact source, output and patch identities.

Final ISO readback verifies all **51,366 original readable script uses**, all
**98,686 unchanged script commands**, native font payload and hooks, terrain
labels, the intermission header and all **205 chapter-card atlases**. Battle
caption readback checks **51,892 entries with no mismatches**.

Targeted PPSSPP checks cover boot, copied-save loading, selected dialogue,
chapter-card rendering and the intermission header with texture replacement
disabled. All five enlarged map scripts pass actual native allocation and
ISO-read probes from the complete-campaign baseline. The ending and closing
blocks also pass native loading; exact ending text passes a renderer probe,
which does not constitute playing the ending scene.

This remains an **experimental translation**. A full campaign playthrough,
physical PSP testing and complete human proofreading are pending. Some bitmap
interface labels, including the sortie-preparation header, remain Japanese.
Report crashes, clipped text or translation issues with version, route, stage
and an in-game screenshot.

## Translation and credits

This is machine translation produced with language models and then edited.
The complete campaign pass used Sol 6.1 Medium, with six translators sharing
each stage/group, followed by context, terminology and font-fit review.
Terminology follows [Akurasu's MX reference](https://akurasu.net/wiki/Super_Robot_Wars/MX).

Project coordination: **Binh**. Translation, tooling and reverse engineering
were assisted by OpenAI Codex models. Genei LateGo is by **o_tamon**, from the
Genei Latin v2.1 package. README and release organization follow SRW-Z;
patch verification uses Retro Trans Tools.

Tools and English sources are in the [project repository](https://github.com/retro-trans/SRW-MX-Portable).

[GitHub issues](https://github.com/retro-trans/SRW-MX-Portable/issues) or
