### Changes since v0.4.47

- Fixed a PSP upgrade-bonus name-buffer overflow affecting Full Armor Hyaku
  Shiki Kai. Selecting the bonus after saving with fully upgraded weapons
  could damage the menu's return pointer and crash. Both unit and weapon
  bonus windows now use sufficient temporary name storage. Full unit names,
  upgrades and save formats are preserved. A matching native fault is
  reproduced and the correction passes 57 native execution cases; confirmation
  with the reporter's save remains pending.
- Translated additional battle-animation captions on both platforms:
  Support Attack, Support Defend, Double Attack, Open Get, Cannot Attack,
  Sword Cut, Harmonic Field, After Image, Barrier, Nattoru Bullet,
  Ship Support Attack, Field Pierced, God Hand Final and AT Field Neutralized.
  Existing warning colors, outlines and neighboring artwork are retained.
- Shortened the high-maneuver unit's name to **HM Black Selena**, as requested,
  to fit the Pilot Training unit column beside PP. HM means High-maneuver.
- Both native title screens display **v0.4.54 / github.com/retro-trans**.
  Earlier campaign proofreading, PS2 Chapter-30 recovery, interface fixes,
  English branding and movie edits remain included.

### Existing saves

Fully restart the emulator with the updated ISO and load a normal in-game
save. Old emulator save states can restore the previous code and damaged
menu pointers. No upgrade values or save layout are changed by this update.

The PS2 Chapter-30 recovery from v0.4.47 remains: load the affected completed
campaign and open Stage Select. The earlier PSP extra-scenario port still
requires a new game when coming from an older scenario layout; general
save-layout migration is not included.

### Verification and limits

Current ISO checks cover the native unit name, all 21 registered battle
captions and exact title footers. Native execution checks cover the PSP
bonus-menu correction and earlier PS2 rename, map values, Objectives and
Chapter-30 recovery fixes. Every release patch is decoded and checked
against the full target hash with Retro Trans Tools.

Fresh in-game checks of the new captions and short name, the reporter's
bonus-menu save, physical-console testing and a full playthrough remain
pending. Earlier branding/movie playback checks remain pending as documented
in v0.4.47. Some bitmap labels, opening/staff credits and the name-entry
keyboard remain Japanese. The separate repeated Chapter-29 dialogue report
remains under investigation.

Report issues with platform, version, stage, a screenshot and a save when possible.
