English translation of **Super Robot Taisen MX (PS2)** and **MX Portable (PSP)**,
sharing release version **v0.4.32**.

This release includes the completed campaign proofreading and the latest
screenshot corrections, which were absent from the previous public images.

### Apply with Retro Trans Tools

Use [Retro Trans Tools](https://github.com/retro-trans/retro-trans-tools).
Refresh the catalog and use **Automatic**, or download the matching bare
`.xdelta` and use **Apply xdelta**. Use your own matching Japanese ISO or the
exact published English v0.4.29 image for your platform. No ZIP extraction
is needed; game images and saves are not distributed.

### Changes

- Included the complete campaign proofreading, all routes and closing text.
  The [proofreading report](https://github.com/retro-trans/SRW-MX-Portable/releases/download/v0.4.32/PROOFREADING-v0.4.32.html)
  explains each recorded story correction.
- Included Hau Dragon terminology and the Saburota follow-up. Improved
  Saiga's revenge/mask imagery, Burai's strategic-timing line and Ritsu's
  "the man I hate" wording. Changed Quattro's shared attack quote to
  "Come on, hit!". Leina's accurate childish insult remains unchanged.
- PSP: fixed the Parts-menu name-buffer overflow reported when equipping
  Full Armor Hyaku Shiki Kai. The complete unit name is preserved.
- Redrew all chapter titles consistently, including artwork already written
  in English and its duplicate/gallery copies. Corrected **Strange Bait**.
- Preserved earlier name, interface, title-footer, battle-label and startup
  warning fixes. Both title screens display **v0.4.32** and
  **github.com/retro-trans**. PSP retains readable outlined text at the
  bottom right without a dark panel.
- PS2 retains both PSP extra scenarios, native menu fixes, selectable
  original/PSP-style balance, and favorites. Updated text preserves the
  existing event commands and gameplay records; wider new dialogue receives
  PS2-specific line breaks. Three lines use source-checked shorter wording
  to fit the PS2 font and the longest editable protagonist names; these are
  also explained in the proofreading report.

### Verification

Current ISO readback checks cover the full story, native fonts, exact
title-footer versions, retained assets and both PS2 directory views. Native
execution checks cover the PSP Parts regression, Spirit Search, Level Up and
narration, plus the PS2 scenario loaders, deployment, save routines, database
getters and title-state guards. Full and upgrade patches round-trip to the
same verified platform output through Retro Trans Tools.

Fresh emulator boot/playthrough checks for v0.4.32 and physical-console tests
remain pending. The PSP live equip/exit test was previously stopped and has
not been resumed; its buffer fix passes native execution checks. Some bitmap
labels and the Japanese name-entry keyboard remain untranslated. Detailed
scope and results are in `BUILD-TESTS-v0.4.32.json`.

Report issues with platform, version, stage, a screenshot and a save when
possible.
