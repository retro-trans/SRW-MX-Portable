English translation update for **Super Robot Taisen MX (PS2)** and **MX Portable (PSP)**.

### Changes since v0.4.58

- **PSP:** Added a balance selector after **Finish Settings** in New Game. Choose **PS2 - Original** or **PSP - Harder**; PSP is the default. PS2 mode uses the original PS2 base HP and funds rewards for matching units within the PSP campaign. The choice is stored with the save; older saves default to PSP balance.
- **Both platforms:** Shortened the Mass-produced EVA display name to **MP EVA** so it fits beside the level.
- **Both platforms:** Shortened the enemy status reward labels to **Funds** and **PP** to give the values room.
- Both native title screens display **v0.9.0** and **github.com/retro-trans**. Earlier fixes, including the PSP Chapter 55 Outer Space load fix and PS2 Chapter 30 progression fix, remain included.

### Apply with Retro Trans Tools

Refresh the [Retro Trans Tools catalog](https://github.com/retro-trans/retro-trans-tools) and choose **Automatic**, or use **Apply xdelta** with the matching patch below.

| Published English PS2 v0.4.58 | [PS2 upgrade](https://github.com/retro-trans/SRW-MX-Portable/releases/download/v0.9.0/SRWMX-PS2-English-v0.4.58-to-v0.9.0.xdelta) |

Earlier supported public versions can use the existing catalog upgrade routes. Local test ISOs require the full patch applied to the matching original Japanese image.

Restart the emulator with the new ISO and load an **in-game save**. Save states retain old code and resources. The PSP balance selector appears when starting a new game. Existing saves without its setting retain PSP balance. For the Chapter 55 fix, load the intermission save before choosing Outer Space. If upgrading from an earlier PSP scenario layout, follow the save compatibility guidance in the v0.4.54 notes.

### Verification and remaining playtesting

All four patches are decoded and checked against their complete target ISO hashes. The actual ISO title footers, MP EVA name, native Funds/PP drawing and PSP balance code are checked. The PSP selector previously passed an isolated PPSSPP cold boot, controls, cancellation and both choices through the opening; v0.9.0 preserves that executable exactly. Native tests cover both balance tables, menu controls and save serialization/restoration.

Live gameplay saving and reloading with the PSP balance setting, fresh in-game views of the two status-label changes, physical hardware and a complete playthrough remain pending. See the included BUILD-TESTS file for the exact checks and inherited evidence.
