### Changes since v0.4.38

- Fixed the PS2 lockout after Chapter 30. A narrowly guarded completion check
  also recovers the affected completed campaign when Stage Select opens.
  The user confirmed reaching Earth Chapter 31 with the fix.
- Fixed PS2 rename-field corruption and overlap, aligned the map-menu Turns
  and Funds values, and matched the Objectives chapter number to its title.
  The user confirmed the Objectives size/alignment correction.
- Widened PSP's Dendoh form-choice popup so both full English names fit.
- Translated Critical, Shield Defense, Distortion Field, TE Sphere and the
  Sortie Prep header on both platforms.
- Added English **SUPER ROBOT WARS MX** logo artwork inspired by the supplied
  SRW 30 reference, retaining the Portable badge on PSP. Updated the menu and
  story-title textures and both platforms' separate title-intro movies.
- Translated both copyright screens and the opening's final production card.
  Rights-holder names, original years, attribution and production companies
  are retained. Movie container headers, audio packets, frame counts and
  original timestamps are preserved; only bounded video picture data changes.
- Both native title screens show **v0.4.47 / github.com/retro-trans**. Earlier
  campaign proofreading, PSP scenario ports and the Parts crash fix remain.

### Existing PS2 saves

For the specific Chapter-30 all-stages-Clear lockout, boot the updated ISO,
load a normal in-game save, then open Stage Select. This recovery preserves
the existing route and cleared-stage history. Loading an old emulator save
state can restore the old executable.

The earlier PSP extra-scenario port still requires a new game when coming
from an older scenario layout; general save-layout migration is not included.

### Verification and limits

Current ISO readback checks story strings and commands, battle captions,
chapter artwork and exact native version footers. Native execution checks
cover the rename editor, Parts regressions, Dendoh popup, map values,
Objectives footer and Chapter-30 recovery on both routes. All four edited
movie streams fully decode with unchanged dimensions, frame counts and
timing. The original non-video movie bytes, including audio, are identical.
Each release patch is decoded and verified against the complete target hash
with Retro Trans Tools. Detailed evidence accompanies the release.

Fresh emulator playback of the new branding/movie edits and physical-console
testing remain pending. A full playthrough is not claimed. Other opening/staff
credits, some bitmap labels and the name-entry keyboard remain Japanese.
The separate report of repeated Chapter-29 dialogue remains under investigation.

Report issues with platform, version, stage, a screenshot and a save when possible.
