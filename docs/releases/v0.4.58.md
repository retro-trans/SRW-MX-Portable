English translation update for **Super Robot Taisen MX (PS2)** and **MX Portable (PSP)**.

### Changes since v0.4.54

- **PSP:** Fixed the reported Chapter 55 load failure when choosing Outer Space. The game can now load the full English stage script when the usual memory pool is too fragmented. The supplied save reached the opening, scripted battle, deployment, and populated objectives in PPSSPP on v0.4.57. This release retains that executable and stage data.
- **Both platforms:** Translated the battle caption as **Team Attack** to match the menus.
- **Both platforms:** Corrected the speaker name to **Gulfer Emperor** and shortened **Mass-produced Great Mazinger** to **MP Great Mazinger**, including the numbered variants, to fit the unit list.

### Apply with Retro Trans Tools

Refresh the [Retro Trans Tools catalog](https://github.com/retro-trans/retro-trans-tools) and choose **Automatic**, or select **Apply xdelta** and use the matching patch below.

| Your source | Patch |
|---|---|
| Japanese PSP, ULJS-00041 | [Full PSP patch](https://github.com/retro-trans/SRW-MX-Portable/releases/download/v0.4.58/SRWMX-English-v0.4.58.xdelta) |
| Published English PSP v0.4.54 | [PSP upgrade](https://github.com/retro-trans/SRW-MX-Portable/releases/download/v0.4.58/SRWMX-English-v0.4.54-to-v0.4.58.xdelta) |
| Japanese PS2, SLPS-25345 | [Full PS2 patch](https://github.com/retro-trans/SRW-MX-Portable/releases/download/v0.4.58/SRWMX-PS2-English-v0.4.58.xdelta) |
| Published English PS2 v0.4.54 | [PS2 upgrade](https://github.com/retro-trans/SRW-MX-Portable/releases/download/v0.4.58/SRWMX-PS2-English-v0.4.54-to-v0.4.58.xdelta) |

Restart the emulator with the patched ISO and load a normal in-game save. For the Chapter 55 fix, load the intermission save before choosing Outer Space. A save state can restore the old executable. If you are upgrading from an earlier PSP scenario layout, follow the save compatibility guidance in the v0.4.54 notes.

Both ISOs were checked for the new caption and exact v0.4.58 title footer. An in-battle check of the new caption is pending.
