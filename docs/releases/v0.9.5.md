# SRW MX English v0.9.5

This release fixes a PS2 freeze after the player confirms an attack target.
The English battle forecast used fixed-size reads for several action labels,
including Attack and No Counter. The fix copies the complete labels byte by byte.

The reporter completed the full player-initiated battle on the same PS2 Slim
SCPH-70004 using OPL v1.2.0-Beta-2223-45875d with MX4ISO. Their ISO hash matches
the PS2 image produced by this release. [Hardware confirmation and footage](https://github.com/retro-trans/SRW-MX-Portable/issues/1#issuecomment-7220419881)

The PSP build carries the matching v0.9.5 title screen version and the v0.9.0
game content.
