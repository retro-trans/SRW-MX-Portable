English translation of **Super Robot Taisen MX (PS2)** and **MX Portable (PSP)**.
Both platforms now use the same release version: **v0.4.12**.

These are experimental builds. You need your own matching Japanese ISO.
Only patches are distributed.

### Apply with Retro Trans Tools

Download [Retro Trans Tools](https://github.com/retro-trans/retro-trans-tools).

- **PSP:** refresh the catalog, choose **Automatic**, select your original
  Japanese ISO or exact published English v0.4.9 ISO, then patch. **Apply xdelta**
  also works with either matching PSP patch below. Published v0.4.1 can upgrade
  through v0.4.9 using the previous release's upgrade patch.
- **PS2:** download and extract **SRWMX-PS2-English-v0.4.12.zip**. Choose
  **Apply xdelta**, select your original Japanese PS2 ISO and the extracted
  **SRWMX-PS2-English-v0.4.12.xdelta**, and choose an output location. PS2 uses
  the manual route because the catalog currently describes one platform per
  GitHub release. The archive includes its own build manifest and validation.

Keep source/checksum verification enabled. Other regional editions and local
test builds with different hashes are not supported patch inputs. PS2 and PSP
patches are separate; selecting a PSP patch does not convert a PS2 game.
Use an **in-game save** and restart when changing builds. Emulator save states
retain old code and resources.

### PSP changes since v0.4.9

- Fixed Level Up skill buffers that caused skill names and levels to overlap.
- Fixed the unskipped opening narration crash and enlarged narration rows.
- Centered Hero Setup, Partner Setup, Rename Unit, Options, Sound Select and
  Demo Select entries using the actual English font width.
- Translated 80 music titles, using the Akurasu MX BGM list.
- Added exactly one space after the speaker name in parenthesized thoughts:
  `Daisuke (He's being a fool...!)`. Corrected 1,173 lines; all 1,176 thought
  rows pass the spacing and width checks.

The complete campaign, route branches, ending, battle captions and chapter
titles from v0.4.9 are retained.

### First public PS2 build

- English campaign, battle captions, database entries, narration and interface
  text, with a native proportional 4× Latin font.
- Adapted the PSP extra prologue and stage content to the PS2 game.
- Choose **PS2 – Original** or **PSP – Harder** balance when starting a game.
  Harder mode raises base enemy HP by 50% and reduces funds by 20%.
- Choose **three distinct favorite series in both balance modes**. Confirm
  selects/removes a series; Cancel removes the most recent choice. The third
  choice opens a Yes/No confirmation; No returns to editing.
- All three favorites use the native EXP and upgrade-limit bonuses and saved
  favorite mask. Existing saves retain their choices. New Game Plus retains
  inherited favorites, with no duplicate bonus stacking.
- Includes weapon/status/roster/system/save/setup layout fixes and repaired
  CT/AT forecast badges.

The PS2 output is identical to the final local 0.1.18 test image, now distributed
as **0.4.12**. Historical PS2 test reports keep their original version labels.

### Verification and remaining checks

Both platforms' patches are decoded against their specified source images and
must match the complete tested output SHA-256. PSP full and upgrade patches
produce the same image. The PS2 archive follows the Retro Trans release format;
the top-level manifest describes PSP so its existing Automatic upgrade history
remains intact. The versioned checksum file covers every download.

PSP checks include fresh-boot PPSSPP playback through the unskipped opening,
visual checks of the affected menus, native rendering probes, all 203 script
readbacks and all 32 disc files. PS2 checks include all 37 disc files, native
campaign/font/balance/UI regressions, all 1,632 favorite triple/mode combinations,
save-field round trips, bonus calculations and fresh-boot PCSX2 code readback.

**Complete campaign playthroughs and physical-console testing remain pending.**
The PS2 three-choice menu still needs a full visual interaction and actual
memory-card save/reload check; automated native checks cover the selection flow
and saved field, but do not replace that playtest. Some bitmap interface labels
remain Japanese. Report problems with platform, version, stage and screenshot.
