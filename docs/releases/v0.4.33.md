English translation of **Super Robot Taisen MX (PS2)** and **MX Portable (PSP)**,
sharing release version **v0.4.33**.

This release repairs the PSP battle-caption regression introduced during
v0.4.29 source preparation. Five translated batches lost their English fields;
v0.4.32's full PSP rebuild consequently retained Japanese for those quotes.
All 1,705 missing translations are restored from the earlier English sources.

### Changes

- Restored 1,705 PSP battle quotes, including Albero's "I'll end it... your
  fight, and your suffering with it!" and Hugo's "As if you could catch the
  Cerberus!". The PS2 v0.4.32 release already retained these translations.
- Corrected remaining battle uses of Hau Dragon and retained the user's
  Bryst, Est and Mu terminology. The PS2 caption refresh now checks all native
  original quote references while preserving animation subfiles, records,
  flags and text IDs.
- Builds reject missing English battle rows. Source export rejects erasing
  existing translations. Release verification reads every native battle quote
  reference from both actual output images.
- Preserved v0.4.32's completed campaign proofreading, Parts-menu name-buffer
  fix, uniform chapter cards, translated startup warning and interface fixes.
- Both native title screens display **v0.4.33** and **github.com/retro-trans**.
  PSP keeps readable outlined text at the bottom right with no dark panel.

### Verification and limits

The release audit covers battle-caption source completeness and native ISO
readback on both platforms, complete story readback, chapter cards, fonts,
title footers, and retained files. Native execution checks cover the PSP Parts
regression and menu regressions, and PS2 scenario loading, deployment, saves,
database getters and title guards. Every full and upgrade patch round-trips
to the verified output image using Retro Trans Tools.

Fresh emulator playthrough, physical-console and the previously stopped PSP
live equip/exit check remain pending. Some bitmap labels and the Japanese
name-entry keyboard remain untranslated. Existing PS2 saves still use the
earlier scenario layout; the extra-scenario port requires a new PS2 game.
Save migration has not been added. Detailed results are in
`BUILD-TESTS-v0.4.33.json`.

Report issues with platform, version, stage, a screenshot and a save when possible.
