### Changes since v0.4.12

- Corrected name spellings throughout the built game text: **George De Sand**,
  **Albero Est**, **Folia Est**, **Black Selena**, **Bryst** and the **Mu**.
- Changed the default squad name to **Magnet X** and shortened the rename
  caption to **Name**, avoiding overlap. Existing saved names are preserved;
  Reset selects the new default.
- Translated the startup warning, **AT Field**, battle **Will** labels,
  **Defend** caption and tiny status/debuff icons on both platforms.
- Corrected Bahbem's decoy line and redrew Chapter 16's **Blue Meets White**
  title with consistent lettering.
- PSP: corrected Chapter 11's title layout, Spirit Search name/cost spacing,
  Zeorymer defeat conditions, and two long music titles. Polished Rockfell's
  Taiha/Yuratei line.
- PS2: translated missing library headings, rewrapped character/robot
  descriptions, aligned library values, and repaired narration, battle-label
  and remaining system/setup/save UI text and spacing.
- Added the exact build version and `github.com/retro-trans` to the native
  title screens. PSP uses larger outlined text at the bottom right without
  a dark panel; PS2 uses the native title renderer.

The existing English campaign, route branches, ending and PS2 balance/favorite
features are retained. The later whole-campaign proofreading pass, Chapter 17
Saburota follow-up and Hau Dragon source changes are **not included in these
incremental images**; they await a full story rebuild. Reviewed sources in the
repository can therefore be newer than the released game text.

### Verification

Full and upgrade patches decode to the exact same platform output, with the
complete output SHA-256 checked through the Retro Trans release builder.
The shared manifest identifies both editions and every source/patch/output.
The checksum files cover all downloads.

Native title-footer readback verifies the actual ISO version. PSP fresh-boot
checks cover the title menu, supplied save, Magnet X default/Reset and Name
caption spacing. PS2 native checks cover title-state guards, font/renderer
hooks and all unchanged script commands, pointers and disc-file layout.
Detailed live evidence is summarized in `BUILD-TESTS-v0.4.29.json`.

Complete campaign playthroughs and physical-console tests remain pending.
Some bitmap labels and the Japanese name-entry keyboard remain untranslated.
Report issues with platform, version, stage and a screenshot.
