# v0.4.2 — partial English translation

Updated English patch for MX Portable, for the Japanese PSP edition **ULJS-00041**. This is an experimental build covering the prologue and stages **1–30**, including the reviewed route branches; it is not a full-game story translation.

## Apply

Download `SRWMX-English-v0.4.2.xdelta` and use [Retro Trans Tools](https://github.com/retro-trans/retro-trans-tools), **Apply xdelta** mode, with your own matching Japanese ISO. After the public release is imported into its catalog, **Automatic** mode can identify the source ISO and apply the patch. [DeltaPatcher](https://github.com/marco-calautti/DeltaPatcher) also accepts the same file.

```sh
xdelta3 -d -s "Super Robot Taisen MX Portable (Japan).iso" SRWMX-English-v0.4.2.xdelta "SRWMX English v0.4.2.iso"
```

Check source hashes against `BUILD-MANIFEST.json` or `README-v0.4.2.txt`; keep checksum verification enabled. Earlier local English test images are not supported patch sources. Restart the game and use an in-game save when changing builds.

## What's included

- Prologue and numbered stages 1–30 story dialogue, including translated route branches.
- English battle captions, menus, pilot/unit/weapon names, library and other database/interface text from the cumulative 0.4.0 build.
- Proportional Genei LateGo font with a native 4× Latin atlas and the corrected `g` descender.
- Kaine's requested closing message translated in all three occurrences.
- All 67 chapter-card titles, including both starting routes, later routes, the hidden stage and the final stage. All 205 bitmap copies are covered: 160 Japanese copies translated, 45 existing English copies preserved.

Font and artwork changes are applied inside the game. No emulator texture replacement is needed. `FONT-LICENSE.txt` contains the Genei source acknowledgements and SIL OFL terms.

## Validation and remaining checks

The release is built with the Retro Trans standard builder. It applies the xdelta to the original ISO and verifies the entire reconstructed output against the target SHA-256. `BUILD-MANIFEST.json`, `VALIDATION.json` and `SHA256SUMS.txt` record the compatible source, exact output and verified patch assets.

The 0.4.2 change preserves every palette and every pixel outside the title rectangles. All other 31 ISO files are unchanged from 0.4.1, retaining its dialogue, battle data, font, code and closing-message fixes. All translated title previews were checked. Selected native PPSSPP checks cover the Stage 1 card and a separate two-line caption probe, with texture replacement disabled. The probe checks renderer bounds and is not a playthrough of that later stage. Earlier battle verification checked 51,892 entries with no mismatches.

A full campaign playthrough and physical PSP testing remain pending. Stage 8 contains a larger script than any original block: watch for **Malloc Memory Over**. Story after stage 30 and many closing messages remain Japanese. Report issues with version, route, stage and screenshot.

## How it was translated

This is machine translation produced with language models and then edited. The campaign pass used Sol 6.1 Medium, followed by context, terminology and text-fit review. Complete human proofreading has not been performed. Terms follow [Akurasu's MX reference](https://akurasu.net/wiki/Super_Robot_Wars/MX).

## Source code and contribute

Tools, English translations, glossary and technical notes are in the [project repository](https://github.com/retro-trans/SRW-MX-Portable). GitHub's source-code archives are repository snapshots, separate from the `.xdelta` game patch. They contain no game ISO or original Japanese dialogue dump.

Bug reports, proofreading and playtesting are welcome through [GitHub issues](https://github.com/retro-trans/SRW-MX-Portable/issues) or [the Retro Trans Discord](https://discord.gg/MssepShjmB).

No complete game images are included. Apply the free patch to a game copy you own; do not sell the patch or pre-patched images.
