# Stage map: which script block belongs to which stage

Generated by `tools/stage_map.py` and stored as data in `work/source/stage_map.json`.
Stage numbers and English titles come from akurasu's [MX Portable flow chart](https://akurasu.net/wiki/MXPFlow_Chart).

## How the game links scripts to stages

- **MAP_ADD.BIN** holds 203 `SRWL` script blocks, starting at sector 0x579C (byte 0x2BCE000).
  The sector table at BOOT.BIN 0x2791F0 lists that sub-archive start.
- **BOOT.BIN 0x27CA20**: 203 × u32, the sector offset of each block relative to 0x579C.
- **BOOT.BIN 0x27D3A8**: 203 × u32, pointers to each block's name. Address = file offset − 0x60.
  The names are sorted alphabetically, and entry *i* of both tables describes the same block.
- **Name scheme**: `s<PP><route><N>0` is the map (battle) script of the *N*-th stage in part *PP*.
  `i<PP><route><N>b` is the scene before that map and `…a` is the scene after it.
  The route letter is `r`/`s` (Real/Super) in part 0 and `e`/`s` (Earth/Space) in parts 3 and 6; it is blank elsewhere.
  Each map script names its own `b` and `a` scenes.
- **STATIC2_ADD.BIN 0x1FF8A8**: 69 scenario records of 0x80 bytes each, with the title at +0.
  The chapter summaries start at 0x201C30 and are in the same order.

## Verification

Every map script's victory and defeat conditions were compared with the flow chart. All stages with
distinctive conditions match, including the Ogre/Ramiel double map (8), persuading Koji (10), Valkyrie (11),
Gilgilgan (17E), boarding the Nadesico B (15S), Amuro (16S), Gulver FXII (18S), Vivace (23), Daimos 50% (24),
the Data Weapons (25), Dragonsaurus (33E), Nadesico in 7 turns (30S), Ragou (31S), the Mass Driver (32S),
Bardiel (36), Mors (38), the Spiral Castle (39), Largo (40), Ogre/Gades (44), Legacy (45), Kaine (46),
Hokushin (47), Zuril/Gandal (48), stages 51, 52 and 54, FINAL, and the Prologue.

## Notes

- `s0570` (#202) is the hidden stage **「心」を蝕むもの** (Mitar, the Zentrum Project lab, Medius Locus).
  The akurasu flow chart does not list it, so it has no English title yet.
- `s0760`, `i076a`/`i076b` and `i063b` are probably **unused**. They use an older line format
  (`Name 「…」` with a space), the game has no title for them, and no live script references `i063b`.
- `end_mes` (#2) holds the joke messages shown after saving. `dummya`/`dummyb` are empty.
- Some stages have no before or after scene. A few scene blocks are empty, for example `i105a`.
- Blocks are numbered in file order (same as `srwl_dump.py`).
