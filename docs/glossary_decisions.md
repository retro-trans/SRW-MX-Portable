# Glossary decisions

Stage24 uses Akurasu's Terminal Colony, Operation Moonraker and source-short
Anaheim. Getter energy and Mutron energy are literal compounds preserving the
source wording. Hokushin's ritual seven/nine luminaries is supported by academic
astral-history sources; Purple Forbidden Enclosure uses official museum wording
for the celestial region. The source-short ritual reference is a contextual
inference and the game's licensed English verse remains unverified. Keep both
numbers, supreme claim, regnal imagery, rightful placement and source cutoff.
See work/glossary/stage24_terms_additions.json for sources and scope.

Stage24 training keeps ki in its martial sense and renders tanden as the lower
abdomen, corroborated by University of Tsukuba research. Gundam Fighter follows
Akurasu; the source GEAR Fighter reply is an explicit human-title joke. These
contextual uses do not extend to ordinary uses of 気 or other machine labels.
See work/glossary/stage24_training_terms_additions.json.

follow Akurasu, retaining source-short forms and only explicit source ranks.

provenance limit. Bug's Denji Dokushuto is provisional romanization of the named
technique, corroborated only in Japanese. Cryptic Heaven and collective Hakke
remain source-short and ambiguous; Stage12's people-only Hakkeshu mapping is
not applied globally. See stage24_postbattle_terms_additions.json.

## Priority (highest first)

Campaign nickname `リョウ` is **Ryo**, while `竜馬` remains **Ryoma**. SRW Wiki's
[Ryoma profile](https://srw.wiki.cre.jp/wiki/流竜馬) explicitly lists this nickname;
Akurasu's [Getter Robo episode list](https://akurasu.net/wiki/Getter_Robo) also
uses Ryo in episode 19's English title, corroborating the spelling. This does not override Akurasu's full
Ryoma Nagare name or refer to the separate Apocrypha character called Ryo.
The preview-first corpus scan corrected five Stage 2 final lines and two prologue
copies used during campaign assembly. Initial drafts and original prologue/build
stay intact. `do_not_touch.json` protects both source-dependent forms.

1. **Manual decision**: `decisions.json` → `names`. Each one needs a reason below.
2. **akurasu.net** (main source, AGENTS.md): the SRW MX pages Character List, Mech List,
   Spirit Commands, Pilot Abilities, Mech Abilities, Parts and Series, fetched by `tools/akurasu_terms.py`.
   - Game skill names with a level suffix (`…Ｌｖ`, `…＋`, `…（３）`) take the akurasu base name plus the suffix.
   - When akurasu has several English names for one Japanese key, akurasu is skipped for that key.
     This affects Qubeley Mk-II (Ple / Ple Two), Medius Locus forms, Gilgazamune, Cell Fighter and 補給.
3. A Japanese name already settled in a higher section (characters > units > weapons > terms).
4. The group that owns the series (`GROUPS` in `tools/make_batches.py`).
5. Otherwise the first group seen; the conflict is logged in `library_check.md`.

Library text is then rewritten from each variant to its canonical spelling in a single pass (`--apply`). System terms
(spirit commands, skills, abilities, parts) are only rewritten inside double quotes, because words like
"Guard" and "Strike" also occur in prose. The per-group files keep the agents' original wording.
Every script-fixed name is listed in `work/glossary/do_not_touch.json`.

## Spelling changes caused by making akurasu the main source

These replace earlier choices that were based on the SRW fandom wiki or Wikipedia:
- Dragonar: Telgum/Flonnes → Tergum/Frons, Stark Deins → Stark Dein, Gewei → Gewai, Maffu → MAFFU.
- Dendoh: Galfa → Gulfer, Knight Gear Oger → Knight GEAR Ogre.
- Evangelion: Evangelion Unit-0x → EVA-0x.
- Nadesico: Black Sarena → Black Sarana. Akurasu spells it this way consistently.
- Spirit Commands use akurasu's primary names (Hot Blood, Sure Hit, Flash, Iron Wall...). The official SRW English
  names (Valor, Strike, Alert, Guard...) are kept as `variants`.
